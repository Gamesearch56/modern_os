# Design language

Material Design 3, applied consistently across the shell, GTK, Qt and
Vivaldi. This document is the visual reference; `docs/MOTION.md` covers
animation and `AGENTS.md` covers the code structure.

## Color

Every color is a **role**, never a literal hex value. Roles come from
`tokens.json` (generated by `matugen` from the wallpaper + active theme
profile) and are exposed to QML as `Colors.color.<role>` — `Colors.qml`
is itself matugen-generated (see `docs/THEMING.md`), which is why colors
live in their own singleton rather than the hand-written `Tokens.qml`
(spacing/shape/elevation, below):

`primary`, `onPrimary`, `primaryContainer`, `onPrimaryContainer`,
`secondary`, `onSecondary`, `secondaryContainer`, `onSecondaryContainer`,
`tertiary`, `onTertiary`, `tertiaryContainer`, `onTertiaryContainer`,
`error`, `onError`, `errorContainer`, `onErrorContainer`,
`surface`, `onSurface`, `surfaceVariant`, `onSurfaceVariant`,
`surfaceContainerLowest` … `surfaceContainerHighest` (5 tonal steps),
`background`, `onBackground`, `outline`, `outlineVariant`,
`inverseSurface`, `inverseOnSurface`, `inversePrimary`, `shadow`, `scrim`.

Plus the full tonal palette (0–100 steps) per key color, for anything that
needs a specific tone rather than a semantic role (e.g. a chart series).

**Default profile:** `tonal-spot-dark` (less chroma on wide-gamut HDR).
Expressive remains in Settings → Design.

**Switchable variants** (matugen scheme types), selectable in Settings →
Design: `Auto` (matches wallpaper mood), `Content`, `Expressive`,
`Fidelity`, `Fruit Salad`, `Monochrome`, `Neutral`, `Rainbow`,
`Tonal Spot`. Light/dark/auto and a contrast level (`standard`, `medium`,
`high`) are independent axes.

## Typography

Interface font: **Inter** (default), switchable to Google Sans Flex or
Roboto. Monospace: **JetBrainsMono Nerd Font**. Never a hardcoded family
string — always `Typography.family.ui` etc., sourced from
`config.json`'s `typography` block (JSON key `ui`, not `interface` —
`interface` is a reserved QML identifier, see docs/DECISIONS.md). Type scale follows MD3
(`displayLarge`, `displayMedium`, `displaySmall`, `headlineLarge/Medium/Small`,
`titleLarge/Medium/Small`, `bodyLarge/Medium/Small`, `labelLarge/Medium/Small`),
computed off a single `typography.scale` (0.8–1.4) so one slider resizes
the whole UI coherently.

## Shape

Corner radius is tiered, not a single constant: `Tokens.radius.small` (8px,
chips/buttons), `medium` (16px, cards/popups), `large` (28px, sheets/panels/
the bar itself when floating), `full` (pill shapes — the bar, chips,
FAB-style buttons). All scale with `config.json`'s `design.cornerRounding`
multiplier.

## Elevation

MD3 uses tonal elevation (a lighter surface tone) more than shadow.
`Tokens.elevation.level0..5` each define a `surfaceTint` opacity and a
(subtle, optional) shadow, applied via a shared `MCard` background — no
component defines its own shadow.

## Wallpaper chroma in chrome

The default theme profile is **expressive-dark** (`design.activeProfile`)
so secondary/tertiary pick up wallpaper hue. `Tokens.elevation` tint
opacities are ~2× the MD3 resting values, then multiplied by
`design.surfaceTint` (default `1`, Design slider ~0.5–2). Selected /
checked / focused chrome uses `primaryContainer` / `onPrimaryContainer`
(or filled `primary`), not a grey `secondaryContainer`. `MIcon` tints
symbolic icons onto the role; launcher app icons set `tint: false`.

## QML primitives

Every overlay and Settings form is assembled from `Widgets/` (stateless,
token-only, listed in `Widgets/qmldir`):

`MText`, `MIcon`, `MButton`, `MIconButton`, `MSwitch`, `MSlider`, `MChip`,
`MTextField`, `MCard`, `MPopup`, `MDialog`, `MTooltip`, `MListItem`
(trailing slot), `MOverlay` (shared overlay chrome + fade/zoom),
`MSectionHeader`, `MHint`, `MField`, `MSelect`, `MCheckbox`,
`MSearchField`, `MKeycap`, `MTable`, `MEmptyState`, `MDivider`,
`MImageTile`, `MAvatar`.

Chrome contract: bar **bubbles** are `BarIsland` pills (`surfaceContainer`,
primary tint, `radius.full`, hover state-layer, equal `Tokens.spacing.sm`
vertical margin). Each widget is its own pill except the wifi/bluetooth
cluster and the battery/control/power cluster. Workspace and taskbar
chips use the same filled-primary nav as Settings (`Chrome.navSelected`).
Menus are `MOverlay` / `MPopup` (title row, close, `MDivider`, hover
border `primary`). Settings uses that overlay; section bodies are
`MSectionHeader` + `MField` rows. Empty = `MEmptyState` centered.
Destructive = `error`. Overlay enter/exit only through `Motion.overlay*`
(`docs/MOTION.md`).

## Layout reference (bar)

Transparent `PanelWindow` with **islands**, not one full-width pill.
Equal top/bottom margin (`Tokens.spacing.sm` when floating). Defaults in
`config.default.json`:

- **Left:** own bubbles for launcher, AI, workspaces, media (only while
  something is playing, or Spotify is open), and taskbar
- **Center:** clock bubble
- **Right:** own bubbles for weather, connectivity (wifi + bluetooth),
  and audio; battery (on battery only) + control-center gear + power
  share one pill. Gear opens the control center, not the Settings app

Tray, mic, performance, vpn, kdeconnect, and the notification
bell stay on disk under `Modules/Bar/widgets/` if a leftover
`config.json` still lists them; they are **not** in Settings → Bar.

## Cross-toolkit consistency

- **GTK 3/4 / Nautilus** — `gtk.css` generated from `tokens.json` (see
  `stow/theme/.config/matugen/templates/gtk.css.template`), libadwaita
  named colors plus `.nautilus-window` rules from MD3 roles. GTK3 Adwaita
  aliases theme Sushi. Folder icons use Papirus-Dark (emblem folders).
  KDE apps keep `modern-folders`. SUPER+E launches
  `apps.defaults.fileManager` (Nautilus by default). Restart Nautilus
  after `theme-apply.sh`. The window is opaque. Sushi floats over it
  (`nautilus-previewer` window rule, `dim_around` scrim). Video/audio
  start muted; changing the Nautilus selection replaces the preview.
- **Qt** — `kdeglobals` `[UiSettings] ColorScheme=modern` plus
  `modern.colors` (KF6 KColorSchemeManager; qt6ct reports
  `ColorScheme::Unknown` and otherwise applies a light Active palette),
  qt6ct-style, and generated `qt6ct` palette (`#AARRGGBB`). Launch
  through `scripts/modern-launch` so `QT_QPA_PLATFORMTHEME=qt6ct` reaches
  the process (Hyprland `hl.env` does not stick after reload). Restart
  Qt apps after `theme-apply.sh`. No `QT_QPA_PLATFORM=xcb`.
- **Phylax** — GTK4 polkit dialog, CSS from `~/.config/phylax/style.css`
  (matugen tokens + chrome radii/type), plus a Hyprland window rule for
  glass opacity, `pin`, and `dim_around`. See `docs/THEMING.md`.
- **Vivaldi** — native theme object plus CSS overlay and a copied wallpaper
  at `~/.config/vivaldi/custom_css/wallpaper` when
  `design.bootScreen.wallpaperOnVivaldi` is on. Fresh installs seed
  `Preferences` and the CSS-mods labs flag (no account data). See
  `docs/THEMING.md`.
- **Plymouth** — boot/shutdown splash themed from the same tokens, see
  `docs/BOOT.md`.
