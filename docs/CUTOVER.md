# Cutover: `bastianweigand` onto this desktop

How to put the daily-driver account on the Quickshell / matugen stack
without painting yourself into a corner, then — after real use — make a
clean break with the previous `~/dotfiles` system.

This is **not** the `devuser` TTY test (`README.md`). That path never
writes `/home/bastianweigand`. This document is the later, explicit
decision to live on the new environment as `bastianweigand`.

Two phases. Do not start Phase 2 until Phase 1 has been the daily
session for days and rewind still works.

| Phase | Goal | Old system | Rewind |
|---|---|---|---|
| **1 — reversible switch** | This account starts `start-hyprland` + Quickshell | Frozen in place (packages, `~/dotfiles`, session files) | Restore the rewind tarball + unstow; old compositor still installed |
| **2 — clean cut** | One desktop, one package set, docs match reality | Removed (configs, unused packages/AUR, caches, leftover units) | Snapper/restic + the restore kit in `docs/BACKUP.md` — not “boot the old Hyprland again” |

Gated `/etc` work (Plymouth/mkinitcpio, sysctl, polkit, ufw, snapper)
stays **off** in Phase 1. There is **no** `install/system/greetd/` in
this repo — do not invent a copy command or enable greetd. See
`docs/ISOLATION.md`.
harder to undo than a home-directory stow. See `docs/ISOLATION.md`.

## What “old” vs “new” means

**Old (keep until Phase 2):** `~/dotfiles`, Waybar / SwayNC / Rofi,
Wallust, the previous Hyprland config tree, `/etc/pacman.d/hooks/package_list.hook`
(writes pkglists back into `~/dotfiles`), whatever currently autostarts
the graphical session on TTY1/TTY2.

**New:** this repo. Quickshell shell, `matugen` tokens, `config.json` +
`hyprland.lua`, stow packages listed in `install/install.sh`
(`hypr shell theme kitty dolphin gtk qt bash git modern systemd xdg
fontconfig`). fastfetch’s config is generated by `theme-apply.sh`.

**Not in scope of either phase:** documents, pictures, Steam libraries,
`~/.ssh`, Proton/Bridge, Vivaldi profile data, `secrets.json`. Those are
user data. Phase 2 deletes *toolkit leftovers*, not the home.

## Phase 1 — switch, keep a rewind

Do this **as `bastianweigand`**, from a TTY or from the old session.
Have a second TTY ready (`Ctrl+Alt+F3`) so a broken compositor is not a
lockout.

### 1. Preconditions

- `devuser` already runs this desktop for real work (`README.md` steps
  1–4). If the bar, Settings, theming, or Vivaldi still fail there, stop.
- `scripts/check-isolation.sh` is clean from this account (no unexpected
  symlinks from `/home/bastianweigand/.config` into this repo).
- You are **not** enabling greetd or copying `install/system/` yet.
  Greetd config **does not exist** in the repo.
- Clone/checkout used for the cutover is one this user can read, e.g.
  `~/CursorProjects/modern_dotfile` or `~/modern_dotfile`.

### 2. Record how the old session starts

Write the answers into the rewind dir (next step). You will need them
verbatim to go back.

```bash
loginctl session-status
systemctl --user list-unit-files --state=enabled
# how Hyprland is launched: ~/.bash_profile, ~/.profile, UWSM, a
# hyprland.desktop, getty autologin — copy the files, do not rely on memory
```

Note the compositor command (often a wrapper, **not** this repo’s
`start-hyprland`). Phase 1 will switch *home configs*; it must not remove
that binary/package.

### 3. Make the rewind bundle (do this before any live stow)

Stow only backs up **conflicting files it replaces**. That is not a
full rewind. Take a dated archive of the session-relevant tree:

```bash
REWIND="${XDG_STATE_HOME:-$HOME/.local/state}/modern/rewind/$(date +%Y%m%d-%H%M%S)"
mkdir -p "$REWIND"

# How the old session started (from step 2)
cp -a --parents \
  "$HOME/.bash_profile" "$HOME/.profile" "$HOME/.bashrc" \
  "$HOME/.config/hypr" "$HOME/.config/systemd/user" \
  "$REWIND/" 2>/dev/null || true

# Whole config/local that the old desktop owns — exclude caches and games
tar --exclude='.cache' --exclude='.steam' --exclude='Steam' \
    --exclude='.local/share/Steam' \
    -czf "$REWIND/home-session.tar.gz" \
    -C "$HOME" \
    .config .local .bashrc .bash_profile .profile .Xresources .gtkrc-2.0 \
    2>/dev/null || true

pacman -Qq > "$REWIND/pacman-Qq.txt"
pacman -Qqm > "$REWIND/pacman-Qqm.txt"
systemctl list-unit-files --state=enabled --no-legend > "$REWIND/systemd-system-enabled.txt"
systemctl --user list-unit-files --state=enabled --no-legend > "$REWIND/systemd-user-enabled.txt"

# Optional: btrfs snapshot of @home if snapper is already configured
# sudo snapper -c home create --description "pre-modern-phase1"

printf '%s\n' "$REWIND" | tee "$HOME/.local/state/modern/rewind/LATEST"
ls -lh "$REWIND"
```

Keep `~/dotfiles` **untouched**. Do not `git commit` inside it. Isolation
policy: this repo never modifies that tree (`docs/ISOLATION.md`).

If `scripts/snapshot-packages.sh` has never been run as this user, run
it once so `install/baseline/` exists (read-only package audit). That
file set is a reference, not a restore.

### 4. Install onto this home (the actual switch)

Dry-run first. `--allow-live-home` is what disables the guard that
protects `/home/bastianweigand`.

```bash
cd ~/CursorProjects/modern_dotfile   # or ~/modern_dotfile
scripts/check-isolation.sh
./install/install.sh --profile full --allow-live-home --dry-run
./install/install.sh --profile full --allow-live-home
```

Use `--profile dev` if you do not want the gaming layer on this pass.
Packages are **additive** (pacman cannot install per-user). Phase 1 does
not uninstall Waybar/Wallust/Rofi; rewind does not require removing
Quickshell either.

After stow:

```bash
systemctl --user daemon-reload
systemctl --user enable modern-shell.service
scripts/theme-apply.sh --wallpaper "$HOME/.config/modern/wallpapers/default.jpg"
# or a file from ~/Pictures/Wallpapers
scripts/doctor.sh
```

Conflict copies from stow live under
`~/.local/state/modern/stow-backups/<timestamp>/`. That is a supplement
to the rewind tarball, not a replacement.

### 5. Start the new session

Log out of the **old** graphical session (or `hyprctl dispatch exit` on
that compositor) so you do not run two Hyprlands as the same user.

On a TTY:

```bash
start-hyprland
```

Do not run the `Hyprland` binary (`docs/BOOT.md`). Confirm: bar, Settings
(Super+I), Super+L control panel, Super+Entf taskbar, Design wallpaper
provider window, `start-hyprland` not `Hyprland`. Do **not** treat
power-menu lock as walk-away security. Shipped UI is English (this
account may already be German via live `config.json`).
`scripts/check-isolation.sh` still clean of gated `/etc`. `stow/greeter`
is unused until a later gated phase.

Leave autologin / greetd as they were. A reboot must still get you a
login you understand. If autologin drops you into the old wrapper, either
point that wrapper at `start-hyprland` **and keep a copy of the old
wrapper in the rewind dir**, or keep starting from a TTY until Phase 2.

### 6. Live with it (days)

Use this account as normal. Keep the rewind dir. Do **not** delete
`~/dotfiles`, do **not** `yay -Rns waybar`, do **not** apply
`install/system/`.

If something is wrong, rewind (next section) instead of “fixing forward”
by deleting old files.

### Rewind (Phase 1 only)

Works only while old packages and `~/dotfiles` still exist.

1. Leave the new compositor: `hyprctl dispatch "hl.dsp.exit()"` (or
   `SUPER+SHIFT+M` once bound). You should be on a TTY.
2. Unstow this repo (does not restore old files by itself):

```bash
cd ~/CursorProjects/modern_dotfile/stow
for pkg in hypr shell theme kitty dolphin gtk qt bash git modern systemd xdg fontconfig; do
  stow --no-folding -D -t "$HOME" "$pkg" || true
done
```

3. Restore the session tree:

```bash
REWIND="$(cat "$HOME/.local/state/modern/rewind/LATEST")"
cd "$HOME"
tar -xzf "$REWIND/home-session.tar.gz"
```

If you also copied individual files in step 3 of Phase 1, copy them back
from `"$REWIND$HOME/..."`.

4. `systemctl --user daemon-reload`. Start the **old** compositor the
   same way you recorded in step 2.
5. `scripts/check-isolation.sh` — after a successful rewind there should
   again be no live-home symlinks into `modern_dotfile`.

Packages installed during Phase 1 stay installed. That does not prevent
the old desktop from running. Uninstalling them is Phase 2 work.

## Phase 2 — backup, then clean cut

Start only after Phase 1 has been daily-driver for long enough that you
would not need the old Waybar session. Rewind to the *old compositor*
is **not** a Phase 2 goal. Recovery is “restore data + reinstall this
repo”.

### 1. Backup first (mandatory)

Follow `docs/BACKUP.md` restore kit, then add a full pass:

- Copy off-machine (or at least off-`@`): `~/.ssh`, `~/.config/modern/secrets.json`,
  Proton/Bridge, `~/.gitconfig.local`, `~/.config/modern/bashrc.local`,
  Vivaldi `~/.config/vivaldi/Default` if you care about a second copy,
  `~/.local/share/modern/`.
- If snapper/restic are still gated and unused, take another
  `home-session.tar.gz` (same excludes as Phase 1) **plus** documents you
  cannot lose. Do not rely only on the Phase 1 rewind dir — you will
  delete the old configs next.
- `pacman -Qqe > ~/pkglist-explicit-$(date +%F).txt` kept next to the
  backup, not only in `install/baseline/`.

Apply gated snapper / restic **before** mass deletes if you want
filesystem snapshots (`install/system/`, headers in those files). If you
skip that, the tarball *is* the backup.

### 2. Stop using the old tree

```bash
# Optional archive, then remove the live old repo
tar -czf "$HOME/.local/state/modern/rewind/dotfiles-archive-$(date +%F).tar.gz" \
  -C "$HOME" dotfiles
# only after the archive exists and you opened it:
# mv ~/dotfiles ~/dotfiles.retired   # or rm -rf once you are sure
```

Do not commit to `~/dotfiles`. Prefer renaming over `rm` for a day.

### 3. Unstow leftovers that are not this repo

After modern stow, stray **regular files** from Waybar/SwayNC/Rofi/Wallust
may still sit next to the new symlinks (stow never deleted them unless
they conflicted). Remove only known old names, not all of `~/.config`:

Typical leftovers (adjust to what you actually had):

- `~/.config/waybar`, `~/.config/swaync`, `~/.config/rofi`
- `~/.config/wallust`, `~/.config/wal`, `~/.cache/wal`, `~/.cache/wallust`
- Old Hyprland `.conf` files that are **not** symlinks into `modern_dotfile`
- `~/.config/hypr/hyprland.conf` if the new stack is `hyprland.lua` only
  (confirm with `ls -l ~/.config/hypr`)

```bash
find ~/.config/hypr ~/.config/waybar ~/.config/swaync ~/.config/rofi \
     ~/.config/wallust -maxdepth 2 \( -type f -o -type l \) 2>/dev/null | head
```

If a path is a symlink into `~/modern_dotfile/stow` or
`~/CursorProjects/modern_dotfile/stow`, leave it.

### 4. Packages: keep manifests, drop the rest (carefully)

```bash
cd ~/CursorProjects/modern_dotfile
scripts/snapshot-packages.sh --diff
```

**Not in any `install/manifests/*.txt`** is a candidate, not an
automatic delete. Keep:

- Firmware, NVIDIA/AMD stacks, anything you installed for hardware
- Printers, VPN clients you still use
- AUR helpers (`yay`) if the manifests still list the bootstrap deps
- Games, Steam, launchers if you use `--profile gaming` / `full`

Old desktop stack that this repo replaced (safe to remove **once Phase 2
backup exists**), if installed and unused:

- `waybar`, `swaync`, `rofi` / `rofi-wayland`, `wallust`, `pywal`
- Other bars/launchers you are not launching

```bash
# example — only packages you confirmed unused
yay -Rns waybar swaync rofi wallust   # edit this list from --diff
yay -Yc                              # unused dependencies
paccache -r                         # old pacman pkg cache (keeps last 3 by default)
```

AUR: `pacman -Qqm` vs `install/manifests/*.aur.txt`. Drop AUR packages
that exist only to support Wallust/Waybar/old GTK hacks. Do not mass
`-Rns $(pacman -Qqm)` — that will remove `cursor-bin`, `quickshell`,
etc. if they are foreign.

Orphans:

```bash
pacman -Qdtq           # review
# pacman -Rns $(pacman -Qdtq)   # only after reviewing the list
```

Caches:

```bash
rm -rf ~/.cache/wal ~/.cache/wallust ~/.cache/swaync
# do not wipe all of ~/.cache while apps are running
```

### 5. Services and hooks

**User:**

```bash
systemctl --user list-unit-files --state=enabled
```

Disable units that started Waybar, old idle daemons, Wallust hooks, or
duplicate notification daemons. Keep `modern-shell.service`,
`hypridle` if this repo starts it, portals, `pipewire`.

**System:**

- `/etc/pacman.d/hooks/package_list.hook` — old `~/dotfiles` writer.
  Phase 2 is when you **remove that hook** (or stop it rewriting
  `~/dotfiles`). This repo does not ship a replacement hook
  (`docs/DECISIONS.md` #11). After removal, `scripts/check-isolation.sh --init`
  if you still use that check, or drop the check (next section).
- Do not disable `hyprpolkitagent` / pipewire / bluetooth.
- Gated files under `install/system/` — apply only files that **exist**
  (Plymouth, sysctl, ufw, tmpfiles, portals). Each file’s header is the
  copy command. Do **not** enable greetd; that tree has not landed.

**`devuser`:** keep until you no longer want a throwaway session, then
`sudo userdel -r devuser`. That deletes `/home/devuser` only.

### 6. Freshen documentation (same change as the clean cut)

Until Phase 2, README/ISOLATION describe a **protected** daily-driver
and a **test** `devuser`. After the live account *is* this desktop, that
story is wrong and dangerous (people will refuse to stow the real home).

Update in one pass (do not do this in Phase 1):

| File | What to change |
|---|---|
| `README.md` | Drop “this machine / second TTY / never `--allow-live-home`” as the default path. Daily install is `install.sh --profile …` on this user. Keep a short historical note + link here. |
| `docs/ISOLATION.md` | Isolation becomes “gated `/etc` still exists”; live-home guard is optional or `MODERN_PROTECT_HOME` is unset. Stop promising `~/dotfiles` is sacred. |
| `docs/INSTALL.md` | `--allow-live-home` is historical for this PC; default target is `$HOME`. |
| `docs/BOOT.md` | Enable `modern-shell.service` on the real account, not “devuser only”. |
| `docs/TROUBLESHOOTING.md` | Isolation symptoms refer to this doc; TTY split is optional. |
| `docs/ARCHITECTURE.md` | `install/baseline/` is an audit snapshot, not “the old user’s live list”. Add this file to the docs tree. |
| `docs/CURSOR-SETUP.md` | Remove “paths from old `~/dotfiles`”. |
| `scripts/check-isolation.sh` / `install/lib/preflight.sh` | Either retire the `/home/bastianweigand` refuse, or set `MODERN_PROTECT_HOME` to a path that is not this account. **Do not leave a guard that blocks the user you just migrated.** |
| `AGENTS.md` | One-line pointer at this file for cutover; no second isolation story. |

`docs/DECISIONS.md` can keep “we rejected Waybar/Wallust” — that is
history, not an operational warning.

Run `scripts/lint-layers.sh` and `scripts/doctor.sh` after the doc pass.

### 7. Verify

```bash
scripts/doctor.sh
scripts/snapshot-packages.sh --diff
systemctl --user status modern-shell.service
# reboot once; confirm start-hyprland / autologin still gets a bar
```

## What this document will not do

- It will not run `install/system/` for you.
- It will not `rm -rf ~/dotfiles` or `userdel`.
- It will not uninstall AUR packages without a reviewed `--diff` list.

Phase 1 success: this user lives in Quickshell **and** `tar -tzf` on the
rewind bundle still lists `.config/hypr` from the old session.

Phase 2 success: no Waybar/Wallust/Rofi on disk, no `~/dotfiles` in
daily use, manifests match what you intend to keep, and README describes
this account as the desktop — not as a museum of the previous one.
